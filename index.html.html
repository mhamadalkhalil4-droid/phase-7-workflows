3REACTIVATION OR NEW MANDATE — Message & Auto-Retry
Codes: E (Card Blocked) · N (Dormant Account) · X (Blocked by Judiciary) · Y (Blocked by Law Enforcement) · Z (Blocked by Central Bank)  ·  Bank submissions counter only
ℹ️ System sends an informational message: if the issue has been resolved no action needed — system will retry. Plus a new mandate link as an alternative. System auto-retries after the waiting period regardless of payer response. No payer response is required or expected.
ℹ️ Two-phase message: early phase includes "if resolved, no action needed — we will try again in [waiting period]" + new mandate link. Late phase (after threshold) drops the "if resolved" text and only shows the new mandate link.

7BOUNCED — TECHNICAL — Notify & Auto-Retry
Code: T (Technical Issues at Paying Bank – Auto NoPay Response from UAEDDS)  ·  Payer notified · Auto-retry · Alert at Max−1 submissions
ℹ️ Code T is a technical failure on the bank side — nothing wrong with the payer's account or funds. The system sends a brief informational message to the payer and retries automatically. When one submission remains before the maximum, the merchant and ops team are alerted.
